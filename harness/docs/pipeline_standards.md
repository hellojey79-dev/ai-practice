# 🛡️ 범용 데이터 크롤링 · 시니어 EDA · 웹 대시보드 표준 룰 (Pipeline Standards)

본 문서는 새로운 웹사이트를 대상으로 데이터 수집, 정제, 통계 분석, 시각화, 리포팅 및 웹 대시보드를 구축할 때 준수해야 하는 엔지니어링 표준 원칙입니다.

---

## 1. 환경 및 폴더 구조 원칙
1. **가상환경 일원화**: 가상환경은 워크스페이스 루트의 단일 `.venv`만 사용하며, 모든 스크립트 실행은 `uv run python <script.py>`로 수행합니다.
2. **표준 4대 폴더 구조 준수**: 새 프로젝트 생성 시 반드시 `images/`, `docs/`, `src/`, `data/` 4개 하위 폴더를 생성하여 역할을 명확히 분리합니다.
3. **상대경로 필수**: 워크스페이스 내 모든 참조 및 코드는 상대경로를 사용합니다.
4. **파이썬 Docstring 의무화**: 모든 `.py` 파일의 최상단 첫 줄부터 한국어 삼중 따옴표(`"""`) docstring을 필수로 작성합니다.

---

## 2. 데이터 크롤링 및 수집 원칙
1. **하이브리드 탐색 우선**: 브라우저 DevTools의 Network 탭(XHR/Fetch)을 역공학하여 API/JSON 엔드포인트 수집을 최우선으로 시도하고, 부재 시 BeautifulSoup/정규식, 동적 SPA일 때만 Playwright를 사용합니다.
2. **서버 친화적 매너**: 요청 간 최소 0.5초 ~ 1.0초의 랜덤 지연시간(`time.sleep`)을 부여하고, 표준 브라우저 User-Agent 헤더를 필수로 전송합니다.
3. **이중 포맷 저장**: 수집된 데이터는 `data/<prefix>_YYYYMMDD.csv` 및 `.json` 형태로 동시에 영구 저장합니다.

---

## 3. 20년차 시니어 EDA 및 시각화 원칙
1. **5단계 기본 탐색 필수**: 데이터 로드 직후 `head(5)`, `tail(5)`, `info()`, `shape`, `duplicated()`, `describe()`를 반드시 실행하고 결과를 제시합니다.
2. **Seaborn 전역 스타일 금지**: `sns.set_theme()`, `sns.set_style()` 등을 일체 사용하지 않으며, Matplotlib 기본 스타일을 유지합니다.
3. **한글 폰트 적용**: `import koreanize_matplotlib`를 필수로 적용하여 한글 깨짐을 방지합니다.
4. **TF-IDF 텍스트 마이닝**: 텍스트 분석 시 형태소 분석기(KoNLPy 등) 대신 `scikit-learn`의 `TfidfVectorizer`를 사용하여 상위 30대 키워드를 추출·표·시각화합니다.
5. **12종 다차원 시각화**: 일변량, 이변량, 다변량 조합으로 최소 10종(권장 12종)의 차트를 `images/` 폴더에 개별 PNG로 저장합니다.
6. **표 동반 및 300자 이상 해석**: **모든 시각화 차트마다 교차표/피봇테이블을 동반하고, 20년차 시니어 분석가 관점의 300자 이상 통계적 해석**을 필수 작성합니다.

---

## 4. Chart.js Bento 웹 대시보드 구축 원칙
1. **Bento Grid 모던 다크 테마**: Slate 900 기반 다크 모드, 반투명 글래스모피즘, 네온 포인트 컬러를 적용합니다.
2. **Chart.js v4 인터랙티브 차트**: 최소 6~7종 이상의 인터랙티브 차트(Bar, Doughnut, Line, Scatter 등)를 제공합니다.
3. **다차원 실시간 필터 & 5대 KPI**: 카테고리/가격대/기간 필터링 및 상단 KPI 카드를 실시간 연동합니다.
4. **독립 실행 보장(No CORS 이슈)**: `data.js`를 자동 생성하여 로컬 파일 더블클릭(`file://`) 시에도 CORS 차단 없이 완벽 구동되도록 설계합니다.
