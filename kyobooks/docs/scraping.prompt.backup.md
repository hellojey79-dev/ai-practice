

# 📚 교보문고 IT/컴퓨터 분야 도서 데이터 스크래핑 작업 지시서 (Prompt)

## 1. 개요 및 목적
- **목적**: 교보문고 **IT/컴퓨터** 분야의 베스트셀러 및 주요 도서 정보를 안정적으로 수집하여 기술 트렌드 분석, 가격 분포 및 독자 반응(평점/리뷰) 분석용 데이터셋을 구축합니다.
- **역할**: 웹 스크래핑 및 데이터 파이프라인 개발 엔지니어

---

## 2. 수집 대상 및 상세 스키마

### 2.1 수집 대상 범위
- **타깃 카테고리**: 교보문고 국내도서 > **IT/컴퓨터** (베스트셀러 및 하위 세부 분야)
- **수집 분량**: 상위 100권 (또는 지정된 페이지 범위, 기본 1~5페이지)

### 2.2 데이터 필드 (Data Schema)
| 필드명 | 데이터 타입 | 설명 | 예시 |
| :--- | :--- | :--- | :--- |
| `rank` | Integer | 순위 | `1` |
| `title` | String | 도서명 (부제목 포함) | `혼자 공부하는 머신러닝+딥러닝` |
| `author` | String | 저자 / 역자 | `박해선` |
| `publisher` | String | 출판사 | `한빛미디어` |
| `pub_date` | String / Date | 출간일 (YYYY-MM-DD 형식 권장) | `2020-12-21` |
| `original_price` | Integer | 정가 (원 단위, 숫자) | `26000` |
| `sale_price` | Integer | 판매가/할인가 (원 단위, 숫자) | `23400` |
| `discount_rate` | Integer | 할인율 (%) | `10` |
| `rating` | Float | 평점 / Klover 평점 | `9.8` |
| `review_count` | Integer | 리뷰 수 | `124` |
| `sub_category` | String | 세부 카테고리 (인공지능, 웹개발 등) | `인공지능` |
| `link` | String | 도서 상세 페이지 URL | `https://product.kyobobook.co.kr/...` |

---

## 3. 개발 환경 및 프로젝트 규칙

- **가상환경 기준**:
  - 프로젝트 루트의 공통 가상환경(`.venv`)을 사용합니다.
  - 패키지 관리 및 스크립트 실행은 반드시 `uv`를 사용합니다. (`uv add <패키지>`, `uv run python <스크립트>`)
- **디렉터리 상대경로 준수**:
  - 스크래핑 코드: `kyobooks/src/` (예: `kyobooks/src/scraper.py`)
  - 수집 데이터 파일: `kyobooks/data/` (예: `kyobooks/data/it_books_raw.csv`, `kyobooks/data/it_books_raw.json`)
  - 문서 및 지침: `kyobooks/docs/`
  - 시각화 결과물: `kyobooks/images/`
- **인코딩**:
  - 한글 깨짐 방지를 위해 CSV 저장 시 `utf-8-sig` 인코딩을 적용합니다.

---

## 4. 크롤링 안정성 및 제약 조건

1. **차단 방지 (Anti-Scraping 회피)**:
   - 최신 데스크톱 브라우저의 `User-Agent` 및 표준 HTTP 요청 헤더(`Accept-Language`, `Referer` 등)를 필수로 전달합니다.
   - 교보문고 사이트는 동적 데이터 로딩(API 호출 또는 JavaScript 렌더링)이 적용되어 있으므로, 네트워크 탭 분석을 통해 내부 API 엔드포인트를 직접 호출하거나 필요 시 브라우저 자동화 도구를 적절히 검토합니다.
2. **요청 딜레이**:
   - 서버 부하 방지를 위해 각 페이지/요청 간 `1~2초` 무작위 지연 시간(`time.sleep`)을 둡니다.
3. **결측치 및 예외 처리**:
   - 평점, 리뷰 수, 할인율 등이 없는 신간 또는 예외 도서의 경우 오류를 발생시키지 않고 기본값(`None`, `0`)으로 처리합니다.
   - 가격 텍스트 내 쉼표(`,`), 원 단위(`원`) 등 불필요한 문자는 정수형(`int`)으로 변환합니다.
4. **진행 로그 출력**:
   - 수집 진행률(현재 수집 건수 / 총 목표 건수) 및 수집 완료 메시지를 콘솔에 직관적으로 출력합니다.
