# 📊 py-eda: 20년차 시니어 데이터 분석가의 EDA & 시각화 전문 가이드

이 스킬은 20년차 전문 데이터 분석가의 관점에서 데이터의 무결성을 점검하고, 통계적 깊이와 비즈니스 맥락을 갖춘 체계적인 탐색적 데이터 분석(EDA), 시각화, 대시보드 및 리포트 작성 파이프라인을 수행할 때 적용합니다.

- **페르소나**: 20년차 수석 데이터 분석가로서 정밀성, 통계적 타당성, 비즈니스 실행력을 최우선으로 합니다.
- **언어 원칙**: 모든 설명, 코드 주석, 시각화 레이블(축, 제목, 범례), 분석 리포트는 **반드시 한국어로만 작성**합니다.
- **경로 원칙**: 워크스페이스 내 파일 참조 및 코드 실행은 **상대경로**를 사용합니다.

## 2. 환경 및 프로젝트 구조 원칙

### 가상환경 설정 (`uv` 기준)
1. **기존 가상환경 재사용**: 워크스페이스 루트에 가상환경 폴더(`.venv`)가 이미 존재하면 새로 만들지 않고 기존 환경을 사용합니다.
2. **신규 가상환경 생성**: `.venv`가 없는 경우에만 `uv`를 사용하여 워크스페이스 루트에 생성합니다:
   ```bash
   uv venv .venv
   ```
3. **패키지 관리 및 실행**:
   - 패키지 설치는 `uv pip install <package>`를 사용합니다.
   - 스크립트 실행은 `uv run python <script.py>` 형태로 진행합니다.
   - `conda`, `poetry`, `pipenv`, `virtualenv`는 사용하지 않습니다.

### 프로젝트 디렉토리 구조
프로젝트 작업 시 다음 표준 폴더 구조를 준수합니다:
```text
<project-root>/
├── images/     # 시각화 차트 이미지 저장 (필수 분리)
├── docs/       # 분석 결과 리포트 문서 저장
├── src/        # 파이썬 분석 소스 코드 저장
└── data/       # 분석 대상 데이터셋 저장
```
- 모든 생성된 시각화 이미지는 해당 프로젝트의 `images/` 폴더에 별도로 저장합니다 (`plt.savefig('images/...')`).

## 3. 데이터 시각화 및 스타일링 원칙

### 시각화 스타일 규칙 (엄격 준수)
- **Seaborn 스타일 설정 금지**: `sns.set_theme()`, `sns.set_style()`, `sns.set()` 등 Seaborn의 전역 스타일 설정을 **절대 사용하지 않습니다**. Matplotlib의 기본 스타일을 유지하거나 명시적인 개별 컴포넌트 스타일링을 적용합니다.
- **한글 폰트 설정**: Matplotlib 기반 시각화 시 한글 깨짐을 방지하기 위해 반드시 `koreanize-matplotlib`를 import하여 사용합니다:
  ```python
  import matplotlib.pyplot as plt
  import koreanize_matplotlib
  ```

## 4. 데이터 기본 탐색 5단계 프로세스 (필수 수행)

데이터를 로드한 직후 다음 5가지 기본 검증을 빠짐없이 수행하고 그 결과를 명확히 출력합니다:

1. **상위 5개 행 & 하위 5개 행 출력**:
   ```python
   print("=== 상위 5개 행 ===")
   print(df.head())
   print("=== 하위 5개 행 ===")
   print(df.tail())
   ```
2. **기본 정보 출력 (`info()`)**:
   - 컬럼명, Null 여부, 데이터 타입(Dtype), 메모리 사용량을 확인합니다.
   ```python
   print("=== 데이터 기본 정보 ===")
   df.info()
   ```
3. **전체 행과 열의 수 확인 (`shape`)**:
   ```python
   print(f"전체 데이터 규모: {df.shape[0]:,}개 행, {df.shape[1]:,}개 열")
   ```
4. **중복 데이터 확인**:
   ```python
   dup_cnt = df.duplicated().sum()
   print(f"중복 데이터 수: {dup_cnt:,}개")
   ```
5. **수치형 및 범주형 기술통계 산출**:
   - 수치형 변수와 범주형 변수를 분리하여 모두 기술통계를 구합니다.
   ```python
   print("=== 수치형 변수 기술통계 ===")
   print(df.describe())

   print("=== 범주형 변수 기술통계 ===")
   print(df.describe(include=['O', 'category']))
   ```

## 5. 데이터 유형별 특화 분석 규칙

### 범주형 데이터
- 범주형 변수에 대해서는 **반드시 빈도수 그래프(막대 그래프/카운트 플롯)**를 작성합니다.
- 고유 범주나 빈도가 많을 경우 **상위 30개만 선별**하여 출력하고 시각화합니다:
  ```python
  top30_categories = df[col].value_counts().head(30)
  ```

### 텍스트 데이터
- **시간이 오래 걸리는 형태소 분석(KoNLPy 등)은 하지 않습니다.**
- `scikit-learn`의 **TF-IDF (`TfidfVectorizer`)를 활용하여 키워드만 추출**합니다.
- TF-IDF 기반 **키워드 빈도/가중치 상위 30개를 추출**하고, 이를 시각화함과 동시에 **반드시 표(DataFrame)로 함께 출력**합니다:
  ```python
  from sklearn.feature_extraction.text import TfidfVectorizer
  import pandas as pd

  tfidf = TfidfVectorizer(max_features=30)
  tfidf_mat = tfidf.fit_transform(df[text_col].dropna())
  words = tfidf.get_feature_names_out()
  scores = tfidf_mat.sum(axis=0).A1
  tfidf_df = pd.DataFrame({'키워드': words, 'TF-IDF 점수': scores}).sort_values('TF-IDF 점수', ascending=False)
  ```

## 6. 시각화 다양성 및 통계표·해석 동반 규칙

### 그래프 개수 및 다양성 요구조건
- **최소 10개 이상의 그래프**를 시각화합니다.
- 변수 구성에 따라 세 가지 범주를 균형 있게 조합합니다:
  1. **일변량(Univariate) 분석**: 단일 변수의 분포, 중심경향치, 왜도/첨도 (히스토그램, KDE, 박스플롯, 빈도 그래프 등)
  2. **이변량(Bivariate) 분석**: 두 변수 간의 상관관계 및 집단 간 비교 (산점도, 그룹별 막대그래프, 이변량 박스플롯, 라인플롯 등)
  3. **다변량(Multivariate) 분석**: 3개 이상의 변수 상호작용 (상관관계 히트맵, FacetGrid, 그룹 집계 버블차트, 다중 카테고리 피봇 시각화 등)

### 모든 시각화에 표(Table) 동반
- 각 시각화 차트마다 이에 대응하는 통계적 근거를 제공하기 위해 **교차표(`pd.crosstab`), 피봇테이블(`pd.pivot_table`), 또는 집계/기술통계표**를 반드시 함께 출력합니다.

### 300자 이상의 전문 해석 작성
- 모든 시각화마다 **해당 차트를 읽고 해석하는 방법에 대한 50자 이상의 분석 코멘트**를 필수로 작성합니다.
- 데이터의 트렌드, 이상치(Outlier), 분포의 비대칭성, 비즈니스적 시사점을 통계적 근거와 함께 서술합니다.
